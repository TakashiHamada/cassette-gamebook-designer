# カセット・ゲームブック デザイナー

全48枚の「カセットテープ型ゲームブック」カードを設計・検証するための静的ウェブツールです。
HTML / CSS / JavaScript のみで動作し、入力内容はブラウザの localStorage に自動保存されます。
（枚数は `js/config.js` の `CARD_COUNT` で変更できます）

## サンプルゲーム「吾輩はネコ」

初回起動時は、すぐ遊べるサンプルゲームが入っています（`js/default-content.js`）。
夏目漱石『吾輩は猫である』へのオマージュで、名前の無い猫がラジカセに録音した音声、という体裁の物語です。

- **リセット**: 全カードを空にします
- **デフォルト**: サンプルゲームを読み込み直します（どちらも確認ダイアログあり・元に戻せません）

謎解きは2箇所です。どちらも「番号を伏せる」選択肢（隠しルート）で、正しい番号を入力した時だけ進めます。

| 場所 | 謎 | 答え |
| --- | --- | --- |
| 中盤（34番） | 迷亭「今日の月と日を掛けた番号へ」 | ラベルの日付 4月10日 → **40番**（先生の起こし方が分かる） |
| 終盤（27番） | 泥棒の声の所までテープを巻き戻す | 23番のラベル「カウンター 043」→ **43番**（トゥルーエンドへの唯一の道） |

エンディングは6種類（19・20・28・32・33・48番）。48番がトゥルーエンドです。

## できること

| 機能 | 内容 |
| --- | --- |
| 編集 | 1〜48番のカードごとに、表面ラベル・裏面の本文（縦書き）・話者と読み方のアドバイス（朗読する人向け。裏面の右側に表示）・選択肢（最大3つ）を入力。遷移元の番号は選択肢から自動で逆引きされます |
| プレイテスト | 「▶ 1番からプレイ」（または編集中のカードから始める「▶ No.〇からプレイ」）で、表面 → 裏返す → 選択肢を選ぶ、の流れを実際に試せます（遷移元の番号をクリックして前のカードへ戻る操作も可能） |
| 整合性チェック | 遷移先の未設定、到達できないカード、行き止まり、エンディングに到達できない、文字数超過などを一覧表示 |
| フローチャート | 1番からの手数ごとに並べた遷移図。ノードをクリックで編集へ |
| 印刷 | A4に表面ページ・裏面ページを実寸で面付け（両面印刷用の左右反転つき） |
| JSON入出力 | バックアップ・共有用。書き出しはゲーム内容のみで、編集中の選択位置やプレイ進行は含みません |

### カードの種類
- **通常**: 選択肢が1つ以上あるカード。選択肢が0個だと警告されます。
- **行き詰まり**: 選択肢がなく、前のカードに戻る前提のカード（意図的な行き止まり）。警告されません。
- **エンディング**: ゴール。1番から到達できるか整合性チェックで確認されます。

### 「番号を伏せる」選択肢（追加機能）
謎の答えが遷移先番号になるケース用です。カード上は番号を表示せず（`＿＿番`）、プレイテストでは番号を入力して進みます。
遷移元の逆引き・整合性チェック・フローチャートには通常の選択肢と同じく含まれます。

## ローカルで動かす

ES Modules を使っているため、`file://` で直接開くことはできません。簡易サーバーを起動してください。

```sh
python3 -m http.server 8000
# → http://localhost:8000/ を開く
```

## GitHub Pages で公開する

1. このリポジトリを GitHub に push する
2. リポジトリの **Settings → Pages** を開く
3. **Build and deployment** の Source を **Deploy from a branch** にし、Branch を `main` / `/ (root)` にして Save
4. 数分後、`https://<ユーザー名>.github.io/<リポジトリ名>/` で公開されます

ビルド工程はありません。ファイルをそのまま配信します。

## 調整値の場所

コードを触らずに見た目・構造を調整できるよう、値を次の場所に集約しています。

| ファイル | 内容 |
| --- | --- |
| `js/config.js` | カード枚数、選択肢の上限、カード寸法(mm)、本文文字数の目安、印刷の面付け、フローチャートのノード寸法、保存キー |
| `css/card.css` の `:root` | カードの配色、フォント、表面ラベル・裏面本文・選択肢の文字サイズと余白 |
| `css/style.css` の `:root` | アプリ画面の配色、フローチャートのノード色 |
| `js/card-render.js` の `CASSETTE_LAYOUT` | カセット絵の各パーツの配置（割合） |

## 保存について

- 保存先は localStorage です（Cookie は容量が4KB程度しかないため使用していません）。
- 内容は `cassette-gamebook:content:v1`、UI状態・プレイ進行は `cassette-gamebook:ui:v1` に分けて保存します。
- ブラウザのサイトデータ消去やシークレットウィンドウでは内容が失われます。**定期的にJSON書き出しでバックアップしてください。**
- 同じブラウザ・同じURLでのみ内容が共有されます（別のPCや別ブラウザには引き継がれません。JSONで移行してください）。

```
js/validate-view.js       整合性チェック画面
js/flow.js                フローチャート
js/print.js               印刷ページ
js/main.js                起動・状態管理・ヘッダー操作
```
